# AI Powered Mental Health Support Chatbot

## Overview
This project is a web-based chatbot that provides basic mental health support and suggestions for users experiencing stress, anxiety, or depression.

The chatbot allows users to interact through text and voice while offering helpful guidance.

## Features
- Interactive chat interface
- Voice input support
- Text-to-speech responses
- Mental health suggestions
- Animated UI

## Technologies Used
HTML
CSS
JavaScript
Web Speech API

## Developed For
Build for Bengaluru 2.0 Hackathon
